# Query

Read `docs/wiki-conventions.md` if you have not this session. Start at `wiki/index.md`, follow it to the relevant pages, and read each one rather than only the most obvious. Go to the file in `raw/` only when the wiki is silent or the exact wording matters.

## How to answer

- Cite a wiki page for each claim, for example: the rent is $900 ([[entities/puddlemere-property-trust]]).
- If the wiki does not know, say that, and name the document that would settle it.
- If pages disagree, or a page has a `## Conflicts` section, show both sides and do not choose.
- Carry over `[inferred]` and `[unverified]` marks instead of stating those claims as fact.
- Give dates as dates. Do not say "next week" or "soon".

## Where the answer goes

A short fact stays in chat. A comparison or analysis someone will want again becomes a page in `wiki/topics/`, added to the index, with one line in the log. A document for someone outside the company goes in `outputs/` as a draft.

If the question exposed a gap or a stale page, mention it. Do not stop to fix it in the middle of answering.
